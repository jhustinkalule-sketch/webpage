# Justin Kalule — Personal Portfolio

A modern, professional portfolio website built with **React**, **Vite**, and **Tailwind CSS**.

## Features

- Premium black & cold executive theme (platinum accents)
- Fully responsive (mobile & desktop)
- Smooth scroll navigation & reveal animations
- Sections: Home, About, Skills, Projects, Experience, Contact
- Featured projects: SafeRoadUG & Tribe Heritage App
- Lucide React icons

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Build for Production

```bash
npm run build
npm run preview
```

## Customize

Edit `src/data/portfolio.js` to update contact details, experience, skills, and project content.

## Tech Stack

- React 19
- Vite 6
- Tailwind CSS 4
- Lucide React (icons)
